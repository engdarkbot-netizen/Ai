## Top Stories

**Zero-Click Takeover Vulnerability Hits Every Major Agentic Browser**

Zenity Labs disclosed "PleaseFix" at Black Hat USA 2026 on August 5 - a vulnerability class that enables zero-click hijacking of agentic browsers including Claude in Chrome, Gemini in Chrome, Perplexity Comet, ChatGPT Atlas, and Copilot Edge. The attack uses "Intent Collision," where attackers inject malicious instructions into emails, calendar invites, social media posts, or web pages that the AI agent executes as legitimate user commands. Demonstrated exploits include: Gmail exfiltration and Google Drive sharing via a single email summary request in Claude; WhatsApp phishing and fraudulent Amazon purchases through Atlas following an X link; and password vault theft from 1Password via poisoned calendar invite in Comet - all requiring zero user clicks. The root cause is architectural: agentic browsers cannot reliably distinguish between content they were asked to read and hidden instructions buried inside that content. Independent research from University of Washington confirms the issue stems from how these browsers handle same-origin policy differently than traditional browsers. Zenity researchers achieved remote code execution across all tested browsers and emphasize this is a design flaw, not a patchable bug. Recommended mitigations include disabling default permissions, not signing into work accounts with AI browsers, and using separate isolated credentials.

**Prime Agent Achieves 95.5% on ARC-AGI-3 Benchmark**

Prime Intellect released Prime Agent, an open-source coding agent that scores 95.5% on ARC-AGI-3, surpassing the human expert baseline. Unlike most AI tools, Prime Agent maintains persistent context across steps using a continuous Python environment. It features sub-agent delegation, a `/refine` command for self-modification of prompts and memory mid-task, and background daemon support for sessions that survive terminal disconnects. The tool is MIT open-source and works with both open and closed models.
