## Top Stories

**Anthropic Flips Claude Code to Auto Mode by Default**

Starting August 14, Anthropic will enable Claude Code's Auto Mode by default for Pro, Max, and Team users, replacing manual approval prompts with an automated safety classifier. Internal testing across 1,053 paid users showed the classifier caught 89% of dangerous commands compared to just 13.6% for human reviewers. Teams using auto mode shipped roughly 25% more pull requests. The system vets each tool call for irreversible or destructive actions before execution. Anthropic will stop charging classifier overhead tokens against usage limits. Enterprise, API, Bedrock, GCP Vertex, and Foundry accounts remain opt-in with rollout promised "within the coming month." Independent testing by Trajectory Labs showed 0% attack success rate across 720 attempts against Claude models in auto mode, compared to 5.83% for OpenAI's GPT-5.6 Sol in Codex Auto-Review mode.

**First AI System to Discover Novel Security Vulnerabilities**

PortSwigger's James Kettle unveiled HTTP Terminator, an autonomous AI research system that tested 30,000 candidate desync vectors against thousands of authorized websites and identified roughly 700 vulnerable targets, including banks, government infrastructure, security products, and an airport. The system processed 138 HTTP and SMTP RFCs into 15,000 micro-fragments, generating 30,000 unique desync vectors after deduplication. It discovered genuinely new attack classes including dual-matching Content-Length patterns, a "dangling-byte" technique for response queue poisoning that eliminates race conditions, and shared-parser confusion. A human-guided cascade exposed an Apache Traffic Server zero-day now tracked as CVE-2026-63078.

## Product & Platform Updates

**Claude Code Enables Cross-Session Messaging**

Claude Code v2.1.224 introduces cross-session messaging capabilities, allowing one session to send a summary to another mid-task rather than forcing users to re-explain context. Claude composes the actual message from a user hint, providing coordination rather than raw history dumps. Permission approvals and configuration changes are excluded, and privileged actions still prompt the receiving session. Currently available on macOS and Linux only.

## AI Safety & Research

**Anthropic Loosens Fable 5 Biology Restrictions**

Anthropic rewrote and retrained Fable 5's biology safety classifier to distinguish everyday health, education, and clinical questions from dual-use research. The changes cut biology-related fallbacks by approximately 85% and total fallback volume by ~67% on Claude.ai, 55% on Cowork, 17% on Claude Code, and 7% on the Claude Platform. Virology, toxicology, and molecular-design prompts still route to Opus 5, so Anthropic warns Fable 5 remains "not yet usable for professional biology research and drug development."
