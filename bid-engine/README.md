# محرّك إعداد العروض — نواة العطلة الأولى

هيكل مشروع جاهز للتشغيل: كراسة شروط PDF ← مصفوفة متطلبات + معايير تقييم + مستندات إلزامية (JSON + HTML للمراجعة).
الهدف من هذه النواة أن تبدأ عطلتك الأولى من كود يعمل، لا من صفحة بيضاء.

## التشغيل

```bash
export ANTHROPIC_API_KEY=sk-...        # أو بدّل المزوّد عبر واجهة LlmClient
mvn package
java -jar target/bid-engine-0.1.0.jar path/to/كراسة.pdf
# النواتج بجانب ملف الكراسة:
#   requirements.json  مصفوفة المتطلبات وحدها
#   tender-spec.json   عقد النظام كاملاً (بيانات المنافسة + المتطلبات + معايير التقييم + المستندات الإلزامية)
#   review.html        مصفوفة المراجعة اليدوية — افتحها بجانب الكراسة وتحقق بنداً-بنداً
```

(بدون Maven: نزّل الاعتماديات في `lib/` وترجم بـ `javac -cp "lib/*"` — المشروع مُرفق معه lib جاهزة ومجرّب ترجمتها.)

## البنية

| الحزمة | الدور |
|---|---|
| `model` | `TenderSpec` و`Requirement` — عقد النظام كله |
| `pdf` | استخراج النص صفحة-صفحة + كاشف الكراسات الممسوحة |
| `pipeline` | التقطيع + `RequirementExtractor` (قلب المشروع) + `TenderInfoExtractor` (البيانات التعريفية، معايير التقييم، المستندات الإلزامية) |
| `llm` | واجهة مجردة للمزود + تنفيذ جاهز بإعادة محاولة تلقائية للأخطاء العابرة (بدّله بحرية) |
| `report` | تصدير مصفوفة المراجعة `review.html` — جدول عربي بسيط بعمود تحقق يدوي |

## قاعدتا أمان غير قابلتين للنقاش (مطبّقتان في الكود)

1. **بند بلا اقتباس حرفي من الكراسة = بند مرفوض.** `sourceQuote` إلزامي، والكود يرمي أي بند بدونه. هذا حائطك ضد الهلوسة — لا تُضعفه أبداً مهما أغرتك "زيادة الاكتمال".
2. **الناتج مسودة للمراجعة البشرية دائماً.** معيار نجاح العطلة الأولى هو تحققك اليدوي بنداً-بنداً من 3 كراسات حقيقية (دقة تفوق 90%) — لا نجاح الترجمة.

## حالة الحافة رقم 1 — مكتشفة أثناء تجهيز هذه النواة

جرّبنا الخط على PDF عربي حقيقي: الاستخراج يعمل، لكن **ترتيب الكلمات العربية قد يخرج معكوساً أو مبعثراً** («التنفيذية الخلاصة» بدل «الخلاصة التنفيذية») — سلوك معروف لاستخراج النص من PDF عربي حسب طريقة توليد الملف. النماذج اللغوية تتعامل مع النص المبعثر بشكل جيد مفاجئ، لكن:
- راقب أثره على دقة `sourceQuote` (المطابقة الحرفية قد تحتاج تطبيعاً للمسافات والترتيب).
- كل كراسة من مصدر مختلف (Word، ماسح، نظام قديم) سلوكها مختلف — **هذا بالضبط ما يجعل خط الاستخراج هو الخندق التنافسي**: من يحلّ فوضى الوثائق الحكومية العربية يملك ما لا يُنسخ بعطلة.

ملاحظة بيئية: إن ظهرت مشكلة مع أسماء ملفات عربية، شغّل بـ `-Dsun.jnu.encoding=UTF-8 -Dfile.encoding=UTF-8` أو تأكد أن locale النظام UTF-8.

## قائمة العطلة الأولى

- [ ] سجّل في اعتماد كمورد ونزّل 5 كراسات حقيقية من قطاعات مختلفة
- [ ] شغّل الخط على الكراسات الخمس وسجّل: نسبة الصفحات الفارغة، عدد البنود، زمن المعالجة
- [ ] تحقق يدوياً بنداً-بنداً من 3 كراسات — سجّل كل بند خاطئ/ناقص وسببه
- [ ] جرّب مزوّدَي نماذج على نفس الكراسة وقارن جودة العربية (معيار الاختيار الأول)
- [x] أضف استخراج `EvaluationCriterion` والمستندات الإلزامية (نفس نمط `RequirementExtractor`) — `TenderInfoExtractor`، مع نفس حائط الهلوسة (عنصر بلا `sourceQuote` يُرمى)
- [x] تصدير مصفوفة المتطلبات كجدول قابل للقراءة للمراجعة — `review.html`
- [x] معالجة أخطاء إعادة المحاولة لاستدعاءات LLM — تراجع أسّي حتى 4 محاولات على 429/529/5xx وأخطاء الشبكة

## ما لا تبنيه الآن (تحذير الإفراط الهندسي)

لا Spring ولا قواعد بيانات ولا واجهات ولا Docker — كلها تأتي حين يفرضها عميل حقيقي.
كل ساعة على بنية "للمستقبل" ساعة مسروقة من خط الاستخراج الذي يصنع القيمة.
